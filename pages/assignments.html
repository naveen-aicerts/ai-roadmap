Phase capstones

Phase 1 capstone

Build a production-style FastAPI REST API with PostgreSQL, Redis, authentication, request validation, structured logging, migrations and automated tests.

Expected outcome: Independently develop and debug a maintainable Python backend service.

Phase 2 capstone

Train and evaluate a classification model, then build a small neural-network model using PyTorch.

Expected outcome: Explain ML algorithms, evaluate models and describe the architecture behind modern LLMs.

Phase 3 capstone

Production-style multi-provider AI assistant with conversation management, tools, structured responses, streaming and automated evaluation.

Expected outcome: You can independently build LLM-powered backend applications and explain the internals of LLM inference, prompting, model integration and evaluation.

Phase 4 capstone

Multi-tenant enterprise document intelligence platform with advanced RAG, citations, hybrid search, reranking and evaluation.

Expected outcome: You can design, implement, evaluate and optimize RAG systems for real business data.

Phase 5 capstone

Build an enterprise AI operations assistant with multiple specialized agents, LangGraph orchestration, MCP tools, persistent memory, approval workflows and observability.

Expected outcome: You can design and implement controlled agentic AI systems and explain the architecture, trade-offs, security and operational requirements to a senior engineering panel.

Phase 6 capstone

Deploy a production-style, multi-tenant enterprise AI platform with RAG, agents, MCP, authentication, cloud infrastructure, CI/CD, monitoring and automated recovery procedures.

Expected outcome: You can deploy and operate an AI application in the cloud, troubleshoot production issues, improve performance, manage infrastructure costs and explain your architecture decisions.

Phase 7 capstone

Build and present an enterprise AI platform that combines RAG, multi-agent orchestration, MCP, multi-tenant security, an LLM gateway, cloud deployment, observability and cost governance.

Expected outcome: You can demonstrate the full lifecycle of an enterprise AI solution—from business requirements and architecture to implementation, deployment, security, monitoring and technical leadership.

Phase 8 capstone

Build a complete enterprise AI platform incorporating the advanced subjects from this phase.
